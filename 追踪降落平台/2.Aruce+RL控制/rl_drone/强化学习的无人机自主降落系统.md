# RL-Drone-Landing: 基于强化学习的无人机自主降落系统

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/release/python-380/)
[![ROS: Noetic](https://img.shields.io/badge/ROS-Noetic-blue.svg)](http://wiki.ros.org/noetic)

这是一个基于强化学习 (Reinforcement Learning) 的无人机自动降落仿真项目。无人机通过 PPO 算法学习如何在动态变化的 Gazebo 仿真环境中，自主追踪并降落在移动的 Aruco 识别板上。

## 🌟 项目亮点

- **端到端训练**：使用多层感知机 (MLP) 直接将相对位置偏差映射为无人机速度指令。
- **动态目标追踪**：降落平台在 2D 平面上进行李萨如曲线 (Lissajous) 混合随机游走，增强模型泛化性。
- **高鲁棒性环境**：针对 PX4 SITL 容易崩溃的问题，实现了**全自动灾难恢复机制**。当飞控 EKF 锁死时，系统会自动保存模型权重、重启仿真并断点续传。
- **精心设计的奖励函数**：采用基于势能的距离惩罚 (Potential-based Shaping) 和控制平滑度 (Jerk) 约束，消除“刷分”行为并减少电机震荡。

## 🛠 技术栈

- **算法库**: Stable Baselines3 (PPO)
- **环境接口**: OpenAI Gymnasium
- **中间件**: ROS Noetic / MAVROS
- **飞行协议**: PX4 Autopilot (SITL)
- **仿真引擎**: Gazebo 11

## 🚀 快速上手

### 1. 环境准备
确保已安装并配置好 ROS Noetic 和 PX4 SITL 环境。

```bash
# 进入工作空间
cd ~/catkin_ws/src
# 克隆项目 (或将此备份文件夹放入)
# 编译
cd ..
catkin_make
source devel/setup.bash
```

### 2. 启动仿真环境
在一个终端中启动物理仿真世界：
```bash
roslaunch rl_drone_backup rl_sim.launch
```

### 3. 开始训练
在另一个终端中运行训练脚本（支持 GPU 加速）：
```bash
python3 scripts/train_agent.py
```
*注：如果程序因为无人机翻车而崩溃，它会自动处理重启序列并继续训练。*

### 4. 运行演示 (Inference)
加载已训练好的 `ppo_landing_final.zip` 模型进行飞行展示：
```bash
python3 scripts/enjoy.py
```

## 📈 状态与奖励函数定义

- **状态 (Observation)**: `[dx_body, dy_body, dz, vx_body, vy_body, last_actions]`
- **动作 (Action)**: `[vx, vy, vz]` (机轴系速度指令)
- **奖励计算**:
  - 核心：`reward = (prev_potential - current_potential) * 100`
  - 成功：`+1000` (距离中心 < 0.4m 且高度 < 0.3m)
  - 失败：`-100` (翻车/越界/撞地)
  - 时间惩罚：`-0.5` per step
