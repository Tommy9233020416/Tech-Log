# 🚁 XTDrone Multi-UAV Formation Control (Direct MAVROS Architecture)

![ROS](https://img.shields.io/badge/ROS-Noetic-green) ![PX4](https://img.shields.io/badge/PX4-SITL-blue) ![Gazebo](https://img.shields.io/badge/Gazebo-11-orange)

这是一个基于 **ROS Noetic + PX4 + Gazebo** 的多无人机编队仿真项目。

本项目针对原版 XTDrone 仿真环境进行了**底层通信架构的重构**，解决了多机通信延迟、MAVROS 指令丢失 (Ack Lost) 以及模型错乱等痛点。采用**直连 MAVROS (Direct Access)** 的方式，实现了稳定、低延迟的三机编队控制。

## ✨ 核心特性 (Key Features)

* **🛡️ 架构去中间化**：摒弃不稳定的 Python 中间件，直接通过 ROS Service/Topic 与 MAVROS 通信，控制延迟降至毫秒级。
* **🔗 端口严格对齐**：修复了 SITL 仿真中常见的端口错配问题，建立了标准的 `14540` (状态) <-> `14580` (指令) 双向链路。
* **🤝 握手**：实现了 `Zero Velocity Stream -> Offboard Switch -> Arming` 的安全起飞握手流程。
* **💃 编队**：包含基于位置反馈 (Position Feedback) 的 P 控制器，实现了“旋转大三角”的编队表演。

## 📂 文件说明 (File Structure)

| 目录         | 文件名                    | 说明                                                         |
| :----------- | :------------------------ | :----------------------------------------------------------- |
| **shell/**   | `multi_env.sh`            | **环境启动器**。一键拉起 Gazebo、3个 PX4 进程及 MAVROS 节点，并自动注入参数。 |
|              | `kill_all.sh`             | **清理脚本**。强力杀死所有残留的 ROS 和 Gazebo 进程。        |
|              |                           |                                                              |
| **scripts/** | `formation_show.py`       | **编队表演**。三机同步起飞、扩散并在空中进行旋转表演 (P控制)。 |
|              | `direct_swarm_control.py` | **基础控制**。演示直连架构下的同步起降。                     |
| **launch/**  | `indoor3.launch`          | **仿真配置**。修正了端口映射的 3 机 Gazebo 启动文件。        |

## 🛠️ 安装与配置 (Installation)

### 1. 前置依赖
确保你已经安装了以下环境：
* ROS Noetic
* PX4-Autopilot (v1.13 或 v1.14)
* MAVROS
* XTDrone (用于获取 `indoor3` 地图资源)
